# DiaMate-RAG  

DiaMate-RAG is an implementation of a **Retrieval-Augmented Generation (RAG)** system developed for the DiaMate project. It enhances AI responses by retrieving relevant information from a knowledge base before generating answers, improving accuracy and contextual relevance.

## Requirements  

- **Python 3.11** or later  

## Installation  

### Install Python Using Miniconda  

1. Download and install **Miniconda** from the official website:  
   https://www.anaconda.com/docs/getting-started/miniconda/install  

2. Create a new environment:  
   ```bash
   conda create -n diamate-rag python=3.11
   ```
3. Activate the enviroment:
   ```bash
   conda activate diamate-rag
